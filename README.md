# DDSuggest
Daily Deviation Quick Suggest Button

# Userscript to Suggest a Daily Deviation Easier
Adds a small button to a deviation page which autofills the DD Suggest Form. The only thing left to do is select the Artwork's Gallery, optionally add comments, and hit Submit.

# Installation Instructions

### Install a Userscript Manager

First, install a browser extension such as:

* [Greasemonkey](https://addons.mozilla.org/en-US/firefox/addon/greasemonkey/)
* [Tampermonkey](https://www.tampermonkey.net/)
* [Violentmonkey](https://violentmonkey.github.io/)

### Click **[here](https://github.com/exarobibliologist/DDSuggest/raw/refs/heads/main/DDSuggest.user.js)** to install the script...

### Open [deviantART.com](https://www.deviantart.com/exarobibliologist/art/The-Scrolling-Man-1370968784)

You should see the button in the upper-right corner of the deviation page.
